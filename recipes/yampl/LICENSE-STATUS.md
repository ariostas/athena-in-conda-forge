# yampl licensing status: unresolved

yampl (https://github.com/vitillo/yampl, written for ATLAS) has no LICENSE file, and its
source files carry no licence headers. ATLAS builds it from a copy of the v1.2 tag in
atlasexternals (`External/yampl`).

This recipe therefore cannot be submitted to conda-forge yet. The licence has to be clarified
with the author and ATLAS. Until then this recipe is only built locally.
