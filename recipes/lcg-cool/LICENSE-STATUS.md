# COOL licensing status: unresolved

COOL (the LCG Conditions Database) is CERN software from the LCG Persistency
Framework. Its repository (https://gitlab.cern.ch/lcgcool/cool) contains no LICENSE file,
and the source files carry no licence headers.

This recipe therefore cannot be submitted to conda-forge yet. The licence has to be clarified
with the CERN CORAL/COOL maintainers, together with CORAL's (see lcg-coral). Until then this recipe is only built locally.
