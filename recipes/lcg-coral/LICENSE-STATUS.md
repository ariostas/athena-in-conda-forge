# CORAL licensing status: unresolved

CORAL (the LCG Common Relational Abstraction Layer) is CERN software from the LCG Persistency
Framework. Its repository (https://gitlab.cern.ch/lcgcoral/coral) contains no LICENSE file,
and the source files carry no licence headers.

This recipe therefore cannot be submitted to conda-forge yet. The licence has to be clarified
with the CERN CORAL/COOL maintainers (the same open question as for the CMS fork packaged in
../cmssw-in-conda-forge). Until then this recipe is only built locally.
